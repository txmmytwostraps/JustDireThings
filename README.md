# Just Dire Things

Just some things Direwolf20 wanted to have...

Unofficial Forge 1.18.2 port. Based on An0mz's 1.20.1 backport and Direwolf20's 1.21.1 version.

- Original mod: https://github.com/Direwolf20-MC/JustDireThings
- 1.20.1 backport: https://github.com/An0mz/JustDireThings

## What's different in this port

- Dire Smithing Table for upgrades, tier upgrades and Paxels. The 1.18.2 smithing table only has two slots.
- Dimension restrictions for the Vault Hunters vault dimensions. Each feature has its own switch.

Needs Forge 40.3.6 or newer. JEI, Patchouli, Curios and Wild Backport are optional.

Report issues with this port here, not to Direwolf20 or An0mz.
